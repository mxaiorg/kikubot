A remote (Streamable HTTP) MCP server. The row is saved to configs/mcp_servers.yaml; secret values go to configs/secrets.env under the env-var names you give here. Assign the key to an agent under its Tools to use it.

Static token

The token is sent on every request as a fixed header. Only the env-var name is written to mcp_servers.yaml; the value goes to secrets.env.

OAuth2

App credentials come from secrets.env. The access + refresh token pair is not stored there — it must be hand-seeded once per agent into data/<agent>/oauth/<key>.json (a JSON object with access_token, token_type: "Bearer", refresh_token, expires_at). Set expires_at in the past to force a refresh on first use; kikubot rotates and rewrites the file from then on.
